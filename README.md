# 退職所得いくら？（taishoku-ikura）

勤続年数と退職金の額（勤続10年2か月で800万円・役員3年で2,000万円・勤続4年の短期 など）を読んで、退職所得控除額を引いた課税退職所得金額を当てる1日5問の学習ゲーム。正解したら「どの計算？」（×1/2・1/2をしない・短期・かからない）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/taishoku-ikura/>

- 答えは、国税庁タックスアンサーの計算（勤続年数の端数は1年に切り上げ。控除は20年以下 40万円×年数（80万円に満たなければ80万円）、20年超 800万円＋70万円×(年数−20)、障害者になって退職なら＋100万円。そのあと×1/2。特定役員は1/2なし、短期は300万円を超える部分は1/2なし。1,000円未満は切り捨て）から出しています（［令和8年4月1日現在法令等］。2026-11-17 に読みました）。
  - No.1420 退職金を受け取ったとき（退職所得） <https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1420.htm>
  - No.2732 退職手当等に対する源泉徴収 <https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2732.htm>
- 退職所得の受給に関する申告書を出している場面です。税額（速算表）・申告書を出さないときの20.42％・同じ年に2つ以上の退職金・役員と従業員の期間が重なる場合は出しません。人と金額はつくりものです。
- このゲームは退職金の税のしくみを知る練習です。税の相談の代わりではありません。実際の税額は、国税庁の資料や税務署で確かめてください。
